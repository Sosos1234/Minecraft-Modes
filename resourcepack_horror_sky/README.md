# Horror Sky Resource Pack

This resource pack adds broken/glitch sky visuals for Minecraft Java Edition:

- `clouds.png` (distorted dark clouds)
- `sun.png` (cracked red-glitch sun)
- `moon_phases.png` (broken moon phases)

## Install

1. Copy `resourcepack_horror_sky` into `.minecraft/resourcepacks`.
2. In Minecraft, open **Options -> Resource Packs**.
3. Enable **Horror Sky Visuals**.

Use this together with the datapack from this repository for full effect.
